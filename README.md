Run `npm install` and `npm start` from the repository root (Node 24+).

- Insurance: http://127.0.0.1:3001/
- Lending: http://127.0.0.1:3001/lending/

Both frontends and APIs share one listener. Set `PORT` to change the shared port. Startup fails if the port is occupied; it never automatically switches ports.
